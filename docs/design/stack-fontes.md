# Fonte de cada marca na stack em fila dupla (pesquisa de 11/11/2026)

Pedido: "Ícone + nome na fonte da marca". Método: CSS que o site oficial de cada marca entrega, mais o catálogo do Google Fonts. Nenhuma página de identidade visual das marcas cita tipografia, porque os logotipos são desenhos próprios; o que está aqui é a fonte que a marca usa no próprio site.

## Fonte original e livre (entra a própria)

| Marca | Fonte | Onde foi vista |
|---|---|---|
| Next.js, Vercel | Geist | nextjs.org, vercel.com |
| GitHub, GitHub Actions, GitHub Copilot | Mona Sans | github.com |
| Node.js | Open Sans | nodejs.org |
| Prisma | Sora (títulos) | prisma.io |
| Supabase | Manrope (títulos) | supabase.com |
| Tailwind CSS, Zod | Inter | tailwindcss.com, zod.dev |
| Notion | Inter (versão própria baseada nela) | notion.com |
| Vitest | Readex Pro | vitest.dev |
| Gemini, Google Workspace | Google Sans | workspace.google.com |

## Custo

Cerca de 11 famílias, cada uma baixando só as letras do nome que escreve (parâmetro `text=` do Google Fonts), na faixa de poucos KB por família.
